Hello Nuked OPN2 Wasm

This repository provides a small WebAssembly build of Nuked-OPN2 for YM2612 / YM3438 experiments in the browser.

It was prepared as one backend candidate for Tetorica FM2612, so the browser tools there can compare ymfm and nuked-opn2 under similar conditions.

Source: docs/index.html | Related code: web/ym2612.js, generated/nuked_opn2_wasm.js
